# HTML-Git

Project tugas HTML dengan versioning Git dan GitHub.

File utama:
- `abel.html`

Elemen HTML yang digunakan:
- Header dan heading
- Paragraph dengan rata kiri, tengah, dan kanan
- Bold, italic, underline, dan warna teks
- Ordered list dan unordered list
- Image
- Hyperlink
- Table
- Form
- Footer
